# Güvenlik

Bir güvenlik açığı bulursan lütfen herkese açık issue açma. GitHub'daki
**Security → Report a vulnerability** (özel bildirim) bölümünü kullan.

- Depoya hiçbir anahtar, token veya `.env` dosyası eklenmez; `.gitignore` bunları dışarıda tutar.
- Kişisel bağlantı ayarı (`.mcp.json`) depoda yoktur; herkes kendi yolunu yazar.
